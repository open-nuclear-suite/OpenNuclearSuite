# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Email
[maxisnote20@gmail.com](mailto:maxisnote20@gmail.com) or use the private
security reporting method configured on the GitHub repository. Include
reproduction steps, affected files or versions, and the potential impact.

If GitHub private vulnerability reporting is enabled, use the repository's
**Security > Advisories > Report a vulnerability** workflow.

## Scope

This repository contains local, educational desktop applications. Model
accuracy questions and teaching-content corrections are not security issues and
may be reported through the normal issue tracker.
